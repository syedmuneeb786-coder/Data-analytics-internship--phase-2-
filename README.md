 Task 2: Customer Segmentation

-> Objective
Cluster customers based on spending behavior to identify distinct groups and suggest targeted marketing strategies.

-> Dataset
Mall Customers Dataset

-> Approach
- Performed Exploratory Data Analysis (EDA) to understand customer features
- Applied K-Means Clustering to segment customers
- Used PCA for dimensionality reduction and visualization
- Determined optimal number of clusters using Elbow Method

-> Results
- Identified distinct customer segments (e.g., high spenders, low spenders)
- Visualized clusters for better interpretation
- Proposed marketing strategies for each segment

-> Tools & Libraries
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

-> Conclusion
Customer segmentation helps businesses design personalized marketing strategies and improve customer engagement.


 Task 3: Energy Consumption Forecasting

-> Objective
Forecast household energy consumption using historical time-series data.

-> Dataset
Household Power Consumption Dataset

-> Approach
- Cleaned and preprocessed time-series data
- Resampled data to appropriate time intervals
- Engineered time-based features (hour, day, etc.)
- Trained and compared models:
  - ARIMA
  - Prophet
  - XGBoost

-> Results
- Compared models using MAE and RMSE
- Visualized actual vs predicted energy usage
- Identified best-performing model

-> Tools & Libraries
- Python
- Pandas, NumPy
- Statsmodels (ARIMA)
- Prophet
- XGBoost
- Matplotlib, Seaborn

-> Conclusion
Time series forecasting enables better energy planning and efficient resource management.
